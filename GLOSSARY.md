# betamac

A practice tool for replying to difficult text messages: the player reads a chat, writes a reply, and the reply is graded against what a good reply should do.

## Language

**Scenario**:
A text conversation between the player and a contact, plus an optional context line, that ends with something for the player to reply to.
_Avoid_: Scene, prompt, exercise

**Reply**:
The message(s) the player writes in answer to a scenario's last message.
_Avoid_: Response, answer, user response

**Criteria**:
The short verb phrases describing what a good reply to a scenario must do; a reply is graded pass/fail on each criterion.
_Avoid_: Rubric, requirements, checks
